# SPI言語対策道場

GitHub Pagesで動く、語句の意味に特化した非公式の練習アプリです。

## 機能

- 語句の意味のランダム出題、経過時間、採点と解説
- 出題語や語句の選択肢に漢字がある場合のふりがな表示
- ブラウザ内の解答履歴・正答率と、最新回答が不正解の問題の復習
- 誰でも追加してほしい語句を送信できるフォーム
- 管理者だけが投稿一覧を確認し、日本語Wiktionaryの語義から問題を作成・公開できる管理画面
- スマートフォン対応、キーボード操作対応

解答記録は端末・ブラウザごとにlocalStorageへ保存します。別の端末への同期はありません。閲覧データを削除すると記録も消えます。

## 語句の追加と公開

トップ画面から送られた語句はSupabaseに保存されます。収録済み、またはすでに送信待ちの同じ語句は受け付けません。投稿者を含む一般の閲覧者は一覧を取得できず、管理者として登録されたユーザーだけが `docs/admin.html` で確認できます。

管理画面では日本語Wiktionaryの公開APIから語義を取得し、4つの誤答候補と組み合わせて問題案を表示します。「応分な」のような形が辞書で見つからない場合は、「応分」のように末尾を外した基本形も自動で検索します。複数の語義がある場合は、問題に使う意味を管理者が選びます。

「な」で終わる語句は、辞書の名詞形の説明をそのまま表示せず、「身分や能力にふさわしい。」のように入力語の形に合う表現へ整えます。誤答選択肢も同じ文末に揃えます。

「日本語に同じ」などの参照だけの説明や、見出し語を繰り返す説明は除外します。「顔立ち。容貌。」のような短い名詞の列挙は「顔立ちや容貌のこと。」のような自然な説明へ整え、送り仮名テンプレート由来の重複も補正します。辞書側の日本語に問題が残る場合は、管理画面の「問題に使う意味」で直接編集できます。最終的な内容は必ずプレビューで確認してください。

確認した問題は「公開待ちリスト」に最大20問までブラウザ内へ保存できます。「GitHubへまとめて登録」を押すとGitHubの確認画面が開きます。`ose-hideaki`本人による登録だけをGitHub Actionsが受け付け、構造検証後に`questions.json`と`docs/questions.js`へ追加します。公開を確認して管理画面の「公開完了」を押すと、対応する投稿をまとめて処理済みにし、届いた語句のリストから消します。サイトのJavaScriptにはGitHubのトークンを保存しません。

「語句の意味」の問題は、正解の位置を保ったまま4つの誤答選択肢を出題のたびにシャッフルします。フォームで新しく作る問題の正解位置は、問題作成時にランダムに決まります。

取得した語義と、それを含む追加問題は日本語Wiktionary由来としてCC BY-SA 4.0の対象になります。アプリは問題内に出典ページへのリンクとライセンスを表示します。

## 起動

```sh
python3 -m http.server 8000 -d docs
```

ブラウザで http://localhost:8000 を開いてください。docs/index.htmlを直接開いて試すこともできますが、保存の挙動はブラウザによって異なるためHTTP経由を推奨します。

## GitHub Pagesで公開する

1. 自分のGitHubアカウントで新しいリポジトリを作成。
2. このフォルダの中身（docs、scripts、prompts、README.md等）をリポジトリのルートへアップロード。
3. Settings → Pages → Build and deploymentで「Deploy from a branch」を選択。
4. Branchを `main`、フォルダを `/docs` にして保存。
5. GitHubが表示する公開URLを開く。

教材ファイルを更新してmainブランチへ反映すると、GitHub Pagesにも反映されます。

## AIで問題を追加する

1. `prompts/new-questions.md` の内容をChatGPTやCodexへ渡す。
2. 出力された配列をUTF-8のJSONファイルに保存。
3. 次のコマンドで構造を確認する。

```sh
python3 scripts/validate_questions.py new-questions.json
```

4. 内容を確認し、標準問題へ追加する。

全利用者向けの標準問題を増やす場合は、既存の `questions.json` と結合し、重複のないIDにしてから実行します。

```sh
python3 scripts/validate_questions.py questions.json --build
```

`docs/questions.js` が更新されます。これをGitHubへアップロードすると公開サイトにも反映されます。
構造検証は正答の妥当性・一意性・著作権の確認を代替しません。AIの再点検だけでなく、人による読解・検討が必要です。

## 問題データ

JSON配列。各要素に `id`, `category`, `question`, `choices`（異なる5つの文字列）, `answer`（0始まりの正解位置）, `explanation` を含めます。`passage` は任意の本文です。初期問題には由来を示す `origin` と `reviewed: false` も記録しています。

## 制作方針

- 実際の試験問題・市販問題集・他サイトの問題文や解説を入力して模倣・言い換えする運用はしません。
- 設問ジャンルを指定し、独立した題材・条件・選択肢・解説を作成します。
- 既存教材と似ていないことは自動保証できません。公開前に内容を点検し、疑義のある問題は除外・修正します。
- SPIの公式サービスであるとの表示や、公式ロゴの使用は行いません。本アプリは試験運営元とは無関係の非公式教材です。

本アプリのコードはMITライセンスです（LICENSE）。AI生成教材の正確性、実際の試験との出題傾向・難易度の一致は保証していません。公式試験の再現ではなく、言語能力の練習を目的とします。
